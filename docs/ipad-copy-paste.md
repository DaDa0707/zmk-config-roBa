# iPadでコピー・貼り付けマクロを試す

`IPAD_COPY_PASTE` は、選択中の内容を `⌘C` でコピーし、250 ms待ってから `⌘V` で現在の場所へ貼り付けます。キーの押下はそれぞれ40 msで、各操作のあとに離します。アプリの切り替えや貼り付け先の移動は行いません。

## ファームウェアと割り当て

1. このブランチのGitHub Actionsが成功したら、成果物の `roBa_R-seeeduino_xiao_ble-zmk.uf2` を取得します。
2. roBa右側（中央側・トラックボール側）をUSB接続してブートローダーモードにし、表示されたドライブへ右側用UF2をコピーします。
3. ZMKPadからroBaへ再接続します。
4. 試したいキーをタップし、「動作」の種類で `IPAD_COPY_PASTE` を選んで「変更」します。パラメーターは使いません。
5. 「キーボードに保存」を押します。

この変更では既存のレイヤー・キー割り当て・動作のノード名を変更していません。Studioで保存した設定を使うため、「Restore Stock Settings」や `settings_reset` は実行しません。新しいマクロはStudio上で後から割り当てます。

## 試し方

1. iPadの「メモ」で試験用のメモを作り、`ABC` と入力します。
2. `ABC` を選択し、マクロを割り当てたキーを1回押します。
3. 選択範囲への貼り付けでは同じ文字に置き換わるため、見た目は `ABC` のままの場合があります。
4. 空行にカーソルを移し、iPadの「ペースト」を実行してクリップボードに `ABC` が入ったことを確認します。
5. 同じ場所でコピー→貼り付けが続くため、見た目だけでは両方の動作が成功した証明になりません。貼り付けを個別に確認したい場合は、別キーに `⌘V` を割り当てて比較してください。

このファイルのマクロを変更・追加した場合もファームウェアの再ビルドが必要です。
